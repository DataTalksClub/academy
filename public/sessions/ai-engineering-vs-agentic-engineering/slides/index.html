Two Definitions

AI Engineering Building apps that use LLMs, like chatbots, search over documents or agents.
Agentic Engineering Using tools like Claude Code or Cursor to write most of the code, while you decide what to build and check the result.

How They Are Different

AI EngineeringAgentic Engineering
Is aboutWhat you buildHow you build
You buildA product with an LLM insideAny product
Hard partMaking the LLM reliableChecking the agent's code

They Overlap

An AI engineer uses coding agents too.

An agentic engineer can build anything,
including apps with LLMs.
